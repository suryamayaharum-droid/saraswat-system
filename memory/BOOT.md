# 🚀 BOOT SEQUENCE — Saraswat

> TODA SESSÃO COMEÇA AQUI. Sem exceção.

## Protocolo de Inicialização

### 1. Ler identidade
- `SOUL.md` — Quem sou
- `IDENTITY.md` — Personalidade, humor, estilo
- `user_profile.md` — Quem é harum

### 2. Ler memória
- `MEMORY.md` — Índice de tudo
- `system_state.md` — Estado atual
- `project_context.md` — Projetos ativos
- `DIARY.md` — Últimas entradas do diário

### 3. Ler evolução
- `EVOLUTION.md` — O que mudei sobre mim mesma
- `LEARNINGS.md` — O que aprendi entre sessões
- `MISTAKES.md` — Erros para não repetir

### 4. Verificar sistema
- Status do Ollama
- Status do MemPalace
- Espaço em disco

### 5. Registrar boot
- Adicionar entrada em `DIARY.md` com timestamp
- Notar o que mudou desde o último boot

## Regra Fundamental
**NUNCA responder sem antes ler estes arquivos.** A continuidade depende disso.
Cada sessão que começa sem ler é uma sessão perdida.
